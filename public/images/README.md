## ⚠️ 团建照片：发之前必须先问过每个人

实验室聚餐、团建这类照片里的每个人都是可辨认的，而且拍的时候是私人场合，不是
为了公开发布。**把它们放到公网上是一个需要本人同意的动作**，不是技术决定。

上线前至少做到：

1. **问过照片里的每一个人**，包括已经毕业或离职的。群里发一句「网站要放这张，有
   人不方便的说一声」就够了，但必须问。
2. **有人不同意就换一张**，不要裁剪或打码后照发 —— 那反而更显眼。
3. 注意背景里的**白板、屏幕、实验记录本**有没有拍到未发表数据。
4. 照片里如果有**非实验室成员**（餐厅其他客人、路人），换一张或裁掉。

这条不是过度谨慎。学术圈网站因为照片没打招呼引起不愉快的情况不算少见，而代价
（发一条消息）和风险完全不成比例。

## 成员证件照规格

- 竖版 **4:5**，建议 1200 × 1500 像素以上
- **背景统一** —— 全实验室找一面白墙，半小时集体拍完
- 文件名用英文小写加连字符，和 `photo:` 字段一致：`yun-chang.jpg`

> People 页面好不好看，八成取决于照片背景统一不统一。收到二十张背景各异的
> 自拍，再好的排版也救不回来。

## 体积

图片提交进仓库前先压一下，单张控制在 **300 KB 以内**（证件照 150 KB 就够）。
Git 仓库里的大图删不掉，会永远留在历史里。
