# 团建 / 实验室生活照片

**放进对应老师的文件夹，就会自动出现在 People 页那位老师那一节。不用改任何代码。**

```
public/images/lab/
  yun-chang/       ← 放这里 → 出现在 People 页「Yun Chang group」那一节
  man-ting-au/
  bingyang-dai/
  cheng-dong/
```

文件夹名 = 老师 profile 的文件名去掉 `.md`（和 `supervisors` 字段填的一样）。
文件夹不存在或者是空的，页面上就什么都不显示 —— 不会出现裂图。

## 排序

**按文件名字母顺序排。** 想控制顺序就在前面加编号：

```
01-annual-dinner.jpg
02-bbq.jpg
03-hotpot.jpg
```

## 规格

- 横版，会被裁成 **4:3**
- 宽度 1600px 以内够用
- **单张压到 300 KB 以内**

## 照片同意

**已获同意（2026-09-02 确认）** —— 当前这批聚餐 / 团建照片，实验室已经跟照片里
的人确认过，可以公开发布。

### 但以后新加照片时，这一步要重做

同意是**针对具体照片**的，不是一次性通行证。往这些文件夹里加新照片时：

1. **问过新照片里的每一个人**，包括已经毕业或离职的。群里发一句
   「网站要放这张，有人不方便的说一声」就够了。
2. **有人不同意就换一张**，不要裁剪或打码后照发 —— 那反而更显眼。
3. 注意背景里的**白板、屏幕、实验记录本**有没有拍到未发表数据。
4. 照片里如果有**非实验室成员**（餐厅其他客人、路人），换一张或裁掉。

有人事后反悔要求撤下，删掉文件重新 push 就行，一两分钟生效。
