### 团建照片 — 只差把文件放进去

同意已经拿到，位置也做好了。剩下的**纯粹是文件传输**：那三张照片目前只存在于
对话里，需要手动存到本地再放进对应文件夹。

```
public/images/lab/yun-chang/     ← 放这里
public/images/lab/man-ting-au/
public/images/lab/bingyang-dai/
public/images/lab/cheng-dong/
```

丢进去，`git add . && git commit && git push`，1–2 分钟后自动出现在 People 页
那位老师那一节。**不用改任何代码。**

- 命名带编号控制顺序：`01-xxx.jpg`、`02-xxx.jpg`
- 会裁成 **4:3** 横版，单张压到 300 KB 以内
- 文件夹空着就什么都不显示，线上不会出现裂图

那三张都是聚餐场景（圆桌、碗碟）。做 Lab Life 够用，但如果想要一张有分量的首页
大图，还是需要实验室里的工作照或者研究示意图。

### 中英双语？

现在是**纯英文**。三个参考站也都是纯英文，学术实验室站这样很正常。

但 PolyU 官方站一般要英文 + 繁中。**这个要问清楚是不是硬性要求** —— 双语意味着所有文案工作量翻倍，而文案恰恰是这类站最贵的部分。如果只是「有更好」，建议先上英文版。
